# United Diesel Care — VS Code Website

A responsive HTML/CSS/JavaScript website for United Diesel Care, Nagercoil.

## Open in VS Code

1. Extract this project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html`.
4. For the best development experience, install the VS Code **Live Server** extension.
5. Right-click `index.html` → **Open with Live Server**.

## Important files

- `index.html` — page structure, SEO and LocalBusiness schema
- `css/style.css` — all styling and responsive breakpoints
- `js/script.js` — navigation, scrolling, animations and front-end form behavior
- `assets/images/` — put the real logo, favicon and workshop photos here

## Before publishing

Replace:
- `https://example.com/` with the real website domain.
- Placeholder workshop/gallery images with genuine business photographs.
- Add the verified Google Business Profile/review URL if available.
- Add verified social links if available.
- Connect the enquiry form to a real backend/form service if enquiries should actually be submitted.

The site intentionally does not fabricate customer testimonials or business statistics.


## Final QA
- Real United Diesel Care workshop/signboard images included.
- Responsive navigation and mobile layouts included.
- Call, WhatsApp and Google Maps CTAs verified.
- Local SEO metadata and AutomotiveBusiness structured data included.
